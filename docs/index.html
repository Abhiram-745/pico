Pico

A Windows computer-use agent that lives as a floating companion — and a phone app that drives it.

Download for Windows Windows 10 2004+ / 11, 64-bit ↓ Get the phone app Installs from your browser — Android & iPhone →

How it works

  1. Install on your laptop. Unzip and run Pico.exe, then add your OpenAI API key in Settings.
  2. Press Ctrl+Shift+P and type what you want done. Pico reads the screen and works.
  3. Start the bridge with node bridge/server.mjs to use your phone. A QR code appears.
  4. Scan it with your phone on the same Wi-Fi. Now you can send tasks and approve actions from your pocket.

Your phone talks to your laptop directly, over your own Wi-Fi. There is no relay server, no account, and nothing is exposed to the internet. Pico still asks before anything destructive, and hands control back to you for passwords and CAPTCHAs.

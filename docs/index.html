Pico

A desktop agent that lives on your screen.

Pico reads your Windows desktop and works it — clicking, typing, scrolling — and stops to ask you before anything it can't undo.

Download for Windows v0.1.7 · Windows 10 2004+ / 11
Use it from your phone →

Setup

  1. Install Node.js if you don't have it.
  2. Run the installer. It downloads, installs and starts Pico — nothing to unzip.
  3. Paste your OpenAI key when Pico asks. That's the whole setup.

Prefer one line? Paste this into PowerShell:

irm https://blurt-ai.me/pico/install.ps1 | iex

How it behaves

It asks first
Sending, deleting, buying, installing — each one waits for you.
It hands back
Passwords, CAPTCHAs and UAC are yours. Pico never types a credential.
You can always stop it
Esc kills a run instantly, from a separate process that only does that.
Your phone stays local
It talks to your laptop over your own Wi-Fi. No relay, no account.
GitHub Safety Releases
Not code-signed — verify the hash before running.
